Build a personal portfolio website for Margaret Thomas.

## Goal

Create a simple, elegant, fast-loading personal portfolio website that can be hosted entirely on GitHub Pages.

The site should feel:

* Clean
* Thoughtful
* Human
* Slightly whimsical
* Professional without being corporate
* Creative without being chaotic

Avoid trendy startup aesthetics, excessive animations, glassmorphism, dark cyberpunk themes, AI-generated design clichés, and overly busy layouts.

The design should age well.

Important: Use the attached file as a reference for the copy to use. Use placeholders for the asset hrefs, which will be populated in the assets folder at a later stage. Use the attached file as the source of truth for the copy, then follow up with copy content that's described in this prompt. Keep the truth and you may enchance the tone where needed.

## Technical Requirements

* Pure HTML, CSS, and JavaScript
* No backend
* No frameworks
* No build step
* No npm dependencies
* GitHub Pages compatible
* Mobile responsive
* Accessible
* Fast loading
* SEO-friendly

Project structure:

```text
index.html
styles.css
script.js
assets/
prompts/
README.md
```

## Visual Design

Colour palette:

* Warm off-white background
* Soft charcoal text
* Subtle warm gray borders

Paired with these colours: 
#47ab9b, #92b7cb, #d0c4fd, #bcabfd, #ab92fd

Typography:

* Elegant and readable
* System fonts preferred
* Strong spacing
* Comfortable reading width

Use generous whitespace.

The design should feel closer to a thoughtfully kept notebook than a software company landing page.

## Animations

Keep animations subtle:

* Gentle hover states
* Soft fade-in on scroll
* No dramatic motion

Respect reduced-motion preferences.

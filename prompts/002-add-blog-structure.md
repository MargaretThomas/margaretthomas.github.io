# Add Blog Structure

Add the structure needed for a blog section to my existing portfolio site.

Do not create any blog post content.

Keep the current design style and tech stack. Do not add frameworks, a backend, CMS, or unnecessary dependencies.

## Requirements

* Add a **Blog** link to the main navigation.
* Create a `/blog/` index page.
* Add a responsive grid layout for future blog post cards.
* Create styling for blog cards with space for:

  * Title
  * Excerpt
  * Date
  * Tags
  * `Read more →`

## Tags

Prepare the blog structure to support multiple tags per post, for example:

* Thin Walls
* AI-Assisted Development
* Behind the Build
* New Idea
* Experiments

Add simple tag-filtering functionality using vanilla JavaScript.

Include an **All** filter.

## File structure

Create a clean structure for future posts, for example:

```text
blog/
  index.html
  posts/
  content/
```

`content/` will contain Markdown source files.

`posts/` will contain the public HTML pages created from those Markdown files later.

Do not create sample or placeholder blog posts.

## Homepage

Add a small **From the workbench** section to the homepage that can later display recent blog posts.

For now, include an empty-state or simple link to:

`View all blogs →`

Do not invent fake posts.

## Blog post styling

Prepare reusable styles for future individual blog pages, including:

* Comfortable reading width
* Headings
* Paragraphs
* Lists
* Blockquotes
* Images and captions
* Tags
* Back-to-blog link

## Important

Inspect the existing site first and reuse its current styles and patterns.

Keep everything static, lightweight, responsive, accessible, and easy for me to manually add blog content later.

Do not create, rewrite, or generate any blog post content.

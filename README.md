# Margaret Thomas Portfolio

This is my personal portfolio: a small, static home for the work, experiments,
milestones, and ideas I want to keep visible.

I’m a Cape Town-based full-stack software developer, curious creative, prompt
explorer, and builder of thoughtful tools. My work often sits at the intersection
of software, language, reflection, and human curiosity.

## What This Portfolio Highlights

- Selected software projects and experiments
- AI and prompt-design work
- Community and developer ecosystem involvement
- Career milestones and learning moments
- Ways to connect with me online

## Featured Work

- **Thin Walls** - A platform for understanding sound in multi-dwelling living spaces.
- **DevMingler** - A developer community focused on mentorship, collaboration, and open source.
- **The Staged Awards** - A Codex skill that turns repository history into playful award ceremonies.
- **Command Clipboard** - A custom GPT for storing and recalling useful terminal commands.
- **Footprints** - A reflective AI project for exploring memory, growth, and personal patterns.
- **The Name Network** - An interactive AI experience about identity, names, and connection.

## Design Intent

The site is intentionally lightweight, calm, and content-first. It uses plain
HTML, CSS, and JavaScript so the focus stays on the work rather than the tooling.
